# LegalHigh 法条检索技能

把「每条法条断言都能给出处」的能力交给你的 Agent：检索返回的是**法条原文 + 引用元数据**，
不是模型复述。三条使用路径按成本递增选择：

## 路径 A：静态导出（零安装）

直接拉取 LegalHigh 的静态开放数据（Cloudflare Pages，无需密钥、无需克隆）：

- 索引：<https://legalhigh.pages.dev/llms.txt>（项目口径 + 数据入口）
- 单法全文：`https://legalhigh.pages.dev/data/laws-md/{law_id}.md`（每法一文件，
  头部含状态/公布/施行/官方来源/权威核对；法集索引见
  <https://legalhigh.pages.dev/data/laws-md/README.md>）
- 术语通俗解释：`https://legalhigh.pages.dev/llms-full.txt`（215 张术语卡，逐条绑定条文）

适合：已知目标法律（如民法典 `civl-2020`）、离线引用、轻量核对。
不适合：跨 108 部法的全文检索——那用路径 B。

## 路径 B：MCP Server（检索/案例/交叉引用/版本沿革）

克隆本仓库后一行接入（stdio）：

```json
{
  "mcpServers": {
    "legalhigh": {
      "command": "python",
      "args": ["<repo>/server/mcp_server.py"]
    }
  }
}
```

（已有部署实例时改用 HTTP：`POST <base>/mcp`，JSON-RPC 2.0。）

九工具（全部只读检索，无生成型工具）：

| 工具 | 用途 |
|---|---|
| `search_articles` | BM25+确定性重排全文检索（命中含来源 URL/施行日期/版本状态；引用式问句自动直查置顶） |
| `resolve_citation` | 法条直查：从问句解析「法名+条号」确定性定位单条（如「民法典第1254条」「个保法第13条」，支持中文数字与之N 子条号；解析失败如实返回不猜测） |
| `get_article` | 取单条条文（含子条号「之N」）+ 公布施行令号 |
| `list_laws` | 108 部受控语料清单 |
| `search_cases` | 最高人民法院指导性案例检索（281 件，官方快照背书） |
| `search_history` | 历史版本全文独立检索（时点查证：1979 刑法→2023 现行等 193 份） |
| `get_xrefs` | 条文双向交叉引用（本文引用谁 / 谁引用本文） |
| `get_amendments` | 修正决定清单与决定全文（145 条立法沿革事件） |
| `get_predecessor` | 前身法全文（民法典九前身、食品安全法前身等 9 部） |

## 路径 C：REST API（自建集成）

FastAPI 实例提供 `/api/search`、`/api/laws`、`/api/cases`、`/api/evals` 等公开只读端点，
`/openapi.json` 与 `/docs` 自带交互文档；接入示例见仓库 README 开发者节。

## 引用纪律（使用本技能输出时的硬性要求）

1. **逐条绑定来源**：引用任何条文必须完整给出——法律名称 + 条号（含子条号）+ 施行日期 + 状态（现行/修正/未生效）+ 官方来源 URL。
2. **原文优先**：条文的表述以工具返回的 `text` 为准，不得凭记忆改写后再当作原文引用。
3. **版本敏感**：同一部法律有多个历史版本（如刑法 1979/1997/2020/2023）；引用前用
   `get_amendments`/`search_history` 确认所引版本就是你想引的版本。
4. **诚实边界**：语料外的法条（行政法规、部门规章、司法解释未收录部分）工具会返回空——
   空结果就是「本语料未收录」，不得臆补。
5. **不构成法律意见**：输出是普法与检索材料，涉具体案件应建议咨询执业律师或拨打 12348。

## 语料质量口径（为什么可以放心引用）

每部法律都有官方来源快照（flk 官方 DOCX 转录 / 官方公报转载 / 人大官网 / 维基文库转录四级渠道），
81 部 flk-docx 源法律经 lawtext + lttxzmj 双独立转录链全量比对（74 部逐字一致，其余为
版本滞后/未收录等已定性差异，零语料文本缺陷），26 部锁定跨上游逐字守卫；版本注册表
108/108 全覆盖。工程指标（检索 hit@5、拒答正确率等）实时公示于
<https://legalhigh.pages.dev/#/quality>——这些是工程指标，不是法律正确率。
