## 1. 这是什么

`web/src` 现在是一个**真实多路由 Web 应用**（React 19 + react-router 7 + Vite，手写组件 + 单一样式表 `styles/global.css`，无组件库依赖）：

- 22 个独立页面 Frame，一一对应文字规格 §5 页面体系（另加法规浏览落地页 `/laws`、证据链页 `/research/:rid/evidence`）
- 每页独立 chunk（React.lazy），共享 AppShell / Design Tokens / 组件库
- 禁止事项已落实：无整图复刻、无 absolute 坐标布局、Dashboard 无 Persona/Roadmap/DesignSystem

## 3. 设计系统落点（规格 §30–§50）

- **Material System（2026-08-29 追加，可验证）**：全局唯一参数源写在 `:root`——`--blur-chrome 30 / --blur-panel 20 / --blur-card 14 / --blur-float 32`、`--mat-sat 150%`、发丝线 `--mat-hairline`、顶部内高光 `--mat-edge`、焦点环 `--ring`（3px #0A84FF）。五档材质 Ultra-Thin(.28)/Regular(.60)/Thick(.78)/Chrome(.52)/Float(.70) 以「半透明叠色基 `--mat-tint` + alpha + backdrop blur + 内高光 + 发丝线」构成 `.material-*` 工具类。
- **真实屏幕采样分层**：body 环境场景（深海军蓝渐变 + 漂移极光色斑 + 细颗粒噪点）在最底层；`.content` 台面半透明（light rgba(245,245,247,.8) / dark rgba(9,9,11,.7)）+ blur24 露出环境光；TopBar 改为**悬浮铬层**（absolute + 内容负 margin 穿入），滚动内容实时从玻璃下经过；Sidebar blur30 采样极光；Toast/Dialog 走 Float 档。**窗内卡片不做各自 backdrop-filter**（合成开销），用与 `.card` 相同的半透明叠色填充（`--mat-card-a`），层次由台面透出的环境光产生；模糊面全窗控制在个位数。
- **深浅色阶（Apple 式）**：Light 基色→前景 #FFFFFF→#1D1D1F，材质为半透明白叠色；Dark #000→#F5F5F7，**elevation = lighter**（海拔越高表面越亮），材质叠色基 tint 44,46,52。两套模式共用同一套语义变量名与材质参数。
- **护栏与降级**：正文阅读区（官方原文 .95 / 案件正文 .9 / 文书纸不透明）强制高不透明度；`@supports not (backdrop-filter)` 全局退化为近不透明；系统 `prefers-reduced-motion` 与设置项均可静止极光。
- **Tokens**：语义变量一套命名两套取值；tone 类挂在 `.main`（TopBar 与内容随路由明暗）。
- **圆角/间距/字号/动效/Focus Ring**：按规格刻进 CSS 变量与组件；Reduce Motion 支持（系统 media + 设置项）。
- **图标**：`components/icons.tsx` 统一线性集（SF Symbols-like）。
- **领域一级组件**（`components/domain.tsx`）：SourceBadge（官方法源/司法案例/学术/域外/AI + 可信等级【强/中/弱】）、ValidityBadge（Verified/Unverified/Outdated/Superseded）、AIBlock（AI 永带标识）、OfficialArticle（官方原文 + 机关/公布/施行/时效字段）、CitationChip/CitationCard（查看原文/复制引用）、EvidenceView（含「缺少可靠依据」红卡）、RiskCardView、ForeignDisclaimer。
- **状态完备**：Default/Hover/Selected/Loading(Skeleton+管线)/Empty(每页定制空态文案)/Error(语料加载失败重试)/Disabled/Focus。

## 4. 数据与证据纪律

- **法条**：`web/scripts/export_laws.py` 从 `server/data/laws`（证据快照语料）导出 `web/public/data/laws.json`（7 部 1,647 条，含机关/公布/施行/来源 URL）；前端**运行时 fetch**，不打包进 JS。禁止在前端手写法条文本。
- **案例**：仅收录可公开查证案件（指导案例 23/24 号、Brown v. Board 347 U.S. 483、Miranda 384 U.S. 436、Donoghue [1932] AC 562）；不确定字段**不写**（如原审法院名），以官方发布文本核对为准；另设 2 条「示例记录」演示 Unverified 状态。
- **语料缺失字段**（3 部法律施行日期为 None）：显示「待核（flk 对照 · M5）」，不手填。
- **合同/工作台/审计**：虚构演示数据一律带「示例」标记；域外资料全程免责横幅。
- **数据源页**：已接入仅本地快照语料；flk/裁判文书网/案例库/legislation.gov.uk/EUR-Lex 等全部「规划接入」。

## 5. 与 server API 的接线（后续 M5 前置）

页面当前为静态演示数据（`src/data/model.ts`，与视图解耦）。接线点：

- 检索/法条：替换 `useLaws()`/`searchArticles` → server 语料 API
- 合同审查/文书起草：CONTRACTS/表单提交 → server 合同审查 API（映射见 v5 记录文档）
- AI 研究/证据：RESEARCHES → case_analysis 模块（保持无状态、行为红线声明）
