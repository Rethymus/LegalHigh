# 设计规格 v3 —「一套语言，两种形态」自适应架构（2026-08-29）

> 定位：v2 解决「身份」（纸与玻璃）；v3 解决「形态」——移动端不是缩小的网页，而是同一设计语言的**另一种母语**。依据：Apple HIG Layout（size classes / 44pt 触摸目标 / 34pt 大标题折叠为 17pt / 安全区 顶部44-59pt·底部34pt / 边距 compact 16pt·regular 20pt）+ 移动 Web 框架实测（Framework7 18,748★、ant-design-mobile 12,041★ 的底栏 Tab / BottomSheet / 底部动作栏模式；GitHub 实测 2026-08-29；注：ionic-framework 现属 ionic-team org，与此前 LegalBench-RAG 迁移同类发现）。

## 〇、目标判据（验收时逐条检查）

在 390×844（iPhone 级）视口下：
1. 主导航在**底部**（玻璃 tab 栏，5 主 tab + 更多），顶部仅紧凑标题栏——绝无桌面顶栏挤压；
2. 主 CTA 在**底部动作栏**（拇指区），不要求用户够页面顶部；
3. 所有可点元素 ≥44px 高；输入框字号 ≥16px（防 iOS 聚焦缩放）；
4. 標題为大标题（衬线 34px 级），滚动后顶栏浮现紧凑标题（17px semibold）；
5. 无横向滚动；表格可横向滑动或已卡片化；底部 tab 栏避让 Home Indicator（env(safe-area-inset-bottom)）。
在 1440×900 下：v2 形态完全保留（顶栏导航、双栏、无底栏）。

## 一、架构机制（Agent G 实施）

1. **Size class**：`useSizeClass()` hook——`matchMedia("(max-width: 767px)")` 监听，`document.documentElement.dataset.sizeclass = "narrow" | "regular"`；CSS 全部用 `html[data-sizeclass="narrow"] …` 分支。**禁止**再写零散 `@media` 断言做形态决策（流式尺寸 clamp 除外）。
2. **meta**：index.html → `viewport-fit=cover` + 两个 `<meta name="theme-color">`（light #faf9f5 / dark #161310，带 media 属性）。
3. **安全区**：`:root { --safe-b: env(safe-area-inset-bottom, 0px); --safe-t: env(safe-area-inset-top, 0px); }`；底栏 `padding-bottom: calc(10px + var(--safe-b))`；narrow 下 `main.page { padding-bottom: calc(150px + var(--safe-b)); }`（tab 栏 58 + 动作栏 64 余量）。
4. **触摸与输入**：narrow 下 `button { min-height: 44px; }`、`.chip { min-height: 38px; }`、`textarea,input,select { font-size: 16px; }`、nav/tab 项 ≥44px。
5. **流式尺寸**（两形态共享）：`.page { padding-inline: clamp(16px, 4vw, 24px); max-width: 1200px; }`；hero/大标题 `clamp()`；`.home-hero h2 { font-size: clamp(30px, 6vw, 44px); }`（替换写死 44px）。
6. **新组件**：
   - `MobileNav`（narrow 专用）：顶部紧凑栏（material-bar：brand glyph + 当前页标题（17px semibold，滚动过大标题后浮现——IntersectionObserver 观察 DocHeader 根元素）+ 右侧 大字/主题 两个图标按钮（44px））；底部 `nav.tabbar`（material-bar，5 主 tab：问答/研究/分析/审查/起草，图标=衬线单字（问/研/案/审/书，28px 圆底）+ 11px 标签，激活=accent 着色；第 6 项「更多」开 BottomSheet：首页/合规中心/设计系统 + 大字/主题开关行）。路由切换自动关 sheet、高亮 tab（含「更多」内的页对应主 tab 高亮策略：合规/设计系统/首页不高亮主 tab）。
   - `BottomSheet`：通用底部队列——fixed 底部面板（material-thick，顶部 grabber 36×4 圆条，圆角 --r-xl 顶部），backdrop rgba(0,0,0,.35)，进出 320ms var(--ease)，点击 backdrop 关闭；`useIsNarrow()` 时才允许渲染（regular 下降级为 inline 面板——由调用方决定）。
   - `MobileActionBar`：narrow 下 fixed 底部动作栏（material-bar，位于 tab 栏上方，`bottom: calc(58px + 10px + var(--safe-b))`），children 为 CTA；regular 下渲染 null（调用方保留 inline CTA，用 `.only-narrow`/`.only-regular` 工具类切换显示）。
7. **工具类**：`.only-narrow { } html[data-sizeclass="regular"] .only-narrow { display:none !important; }`；`.only-regular` 反之；`.table-scroll { overflow-x:auto; -webkit-overflow-scrolling:touch; }`。
8. **App.tsx 集成**：useSizeClass 挂载；narrow 渲染 MobileNav（隐藏 v2 顶栏 nav 与其按钮组——主题/大字移入紧凑栏与更多 sheet）；regular 保持 v2 顶栏。

## 三、验收（主会话）

1. `npm run build` 通过；pytest 不涉（39 绿不回归）。
2. 浏览器 390×844 截图：首页 / 问答（含动作栏）/ 起草（含引用 BottomSheet）/ 更多 sheet；1440×900 回归：首页 / 问答（v2 形态不变、无底栏）。
3. DOM 断言：narrow 下 `data-sizeclass="narrow"`、tabbar 存在、桌面顶栏 nav 隐藏；regular 下反之。
