# LegalHigh 视觉系统规范 — Apple 风格可验证材质层（v1.0，2026-08-29）

> 目标：把「参考 Apple」从文案落成**可核验的参数系统**。本规范每个值与 `web/src/styles/` 中的 CSS 变量一一对应；`web` 内置 `/design` 系统页可逐项目检（配套截图核验）。
> 依据：Apple Human Interface Guidelines「Materials」「Dark Mode」「Typography」（developer.apple.com/design/human-interface-guidelines/，2026-08-29 核验可达）；iOS 系统色/灰阶/字号为 Apple 公开设计资源中的取值（developer.apple.com/design/resources/）【强】。**材料层具体 blur 半径与透明度系本系统校准值**（Apple 未公开内部数值），以「材质阶梯」结构对齐 iOS ultraThin→ultraThick 五级语义。

## 1. 设计原则（对应 HIG Materials）

1. **材质是层，不是颜色**：面板 = 屏幕采样模糊（backdrop-filter）+ 半透明叠色 + 内高光 + hairline 边框的**组合体**，四种属性全部参数化，组合成 5 级可复用材质。
2. **层次来自背景**：全局背景是多层彩色渐变+缓慢漂移的光斑（真实可被采样），材质面板才可能「随背后内容产生层次」。
3. **明暗同构**：每级材质、每个语义色都有 light/dark 两套值，切换不改结构只换值。
4. **可及性是硬约束**：`prefers-contrast: more` 时降透明度保对比；焦点环全局统一；正文对比度 ≥ 7:1（AAA），次要文字 ≥ 4.5:1（AA）。

## 4. 材质层（materials.css，核心可复用件）

统一配方（每级 4 参数：blur、fill、inner-highlight、border），另加全局 `saturate(180%)` 提升毛玻璃质感：

| 材质类 | blur | saturate | Light fill | Dark fill | 用途 |
|---|---|---|---|---|---|
| `.material-ultrathin` | 24px | 1.6 | rgba(255,255,255,.46) | rgba(28,28,30,.42) | 大面积背景层、卡内嵌层 |
| `.material-thin` | 28px | 1.8 | rgba(255,255,255,.58) | rgba(28,28,30,.55) | 次级卡片、输入条 |
| `.material-regular` | 32px | 1.8 | rgba(255,255,255,.72) | rgba(28,28,30,.68) | 标准面板（主卡片、侧栏） |
| `.material-thick` | 36px | 1.9 | rgba(255,255,255,.84) | rgba(28,28,30,.80) | 浮层卡片 |
| `.material-bar` | 40px | 1.9 | rgba(255,255,255,.90) | rgba(18,18,20,.88) | 顶栏/底栏（接近不透明保可读） |

公共属性（全部材质共享，参数化）：
- **内高光**：`box-shadow: inset 0 1px 0 var(--edge-highlight-top), inset 0 0 0 0.5px var(--edge-highlight-soft)`；light `--edge-highlight-top: rgba(255,255,255,.65)`，dark `rgba(255,255,255,.10)`（暗色靠低强度高光维持「玻璃上沿」感）。
- **细边框（hairline）**：`border: 0.5px solid var(--hairline)`；light `rgba(0,0,0,.10)`，dark `rgba(255,255,255,.14)`；2x 屏自动呈 1 物理像素。
- **顶部光带**：`::before` 叠 `linear-gradient(180deg, var(--sheen), transparent 42%)`；light sheen rgba(255,255,255,.38)→0，dark rgba(255,255,255,.07)→0。
- **叠色呼吸**：材质上再叠 `--material-tint`（默认 transparent；风险卡用语义色 @ .08）。

| Token | Light | Dark |

| `--shadow-2` | 0 2px 6px rgba(0,0,0,.08), 0 10px 28px rgba(0,0,0,.10) | 0 2px 6px rgba(0,0,0,.55), 0 12px 32px rgba(0,0,0,.48) |
| `--shadow-3` | 0 6px 16px rgba(0,0,0,.10), 0 20px 48px rgba(0,0,0,.14) | 0 8px 20px rgba(0,0,0,.6), 0 24px 56px rgba(0,0,0,.55) |
| `--shadow-4`(浮层) | 0 12px 32px rgba(0,0,0,.16), 0 32px 80px rgba(0,0,0,.18) | 0 12px 32px rgba(0,0,0,.65), 0 40px 96px rgba(0,0,0,.6) |

规则：dark 模式阴影更重且环境光半径更大（补偿纯黑背景）；材质级越厚阴影越浅（厚材质自带遮蔽感）。

## 6. 焦点环（tokens/focus.css）

- `:focus-visible` 统一：`outline: none; box-shadow: 0 0 0 3.5px var(--focus-ring)`；`--focus-ring: rgba(0,122,255,.45)`（dark: rgba(10,132,255,.55)）；深色 accent 元素上自动叠 `0 0 0 1.5px var(--n0)` 内圈分隔。
- 焦点环与 hairline/内高光互斥计算：焦点时临时压平内高光，避免「双描边」。

## 7. 圆角 / 间距 / 字体 / 动效

- 圆角：`--r-xs 6 / --r-s 10 / --r-m 14 / --r-l 20 / --r-xl 28 / --r-pill 999`（大面板用连续曲率感的大圆角）。
- 间距：4 基网格 `4 8 12 16 20 24 32 40 48 64`。
- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", "Segoe UI", sans-serif`。
- 字阶（iOS 公开字号/行高）：largeTitle 34/41（-0.4 tracking）、title1 28/34、title2 22/28、title3 20/25、headline 17/24 semibold、body 17/24、callout 16/21、subhead 15/20、footnote 13/18、caption 12/16。
- 动效：标准缓动 `cubic-bezier(.25,.1,.25,1)`，微交互 180ms、面板进出 320ms；`prefers-reduced-motion` 时全部降为 0ms。

## 8. 主题机制与降级

- 默认跟随 `prefers-color-scheme`；顶栏切换写入 `document.documentElement.dataset.theme = "light"|"dark"`（用户显式选择优先于系统）。
- 全部颜色/材质变量定义在 `:root`（light）与 `[data-theme="dark"], :root.dark-scheme` 双集合；暗色跟随系统时由 JS 初始化设置 data-theme，避免 FOUC。
- **降级**：`@supports not (backdrop-filter: blur(1px))` 时材质 fill 提升不透明度（+0.16）并取消 saturate，保证层次仍可读（Windows 老内核等环境）。
- **高对比**：`@media (prefers-contrast: more)` 材质 fill → 不透明（--n50/--n100），hairline 加深至 0.2/0.24 alpha，阴影减半。
- **可验证性**：`web/src/pages/DesignSystem.tsx`（路由 `/design`）渲染全部 token 色卡、5 级材质叠在动态背景上的实拍样片、阴影/焦点环演示，逐项标注本规范参数值——规范与实现不一致时该页立即可见。

## 9. 全局背景（毛玻璃的「被采样层」）

- `#app-backdrop`：`position: fixed; inset: 0; z-index: -1`，含 2 层大尺度径向渐变（accent/teal/purple @ 14-20% 透明度，light 稍亮 dark 稍深）+ 3 个缓慢漂移光斑（`@keyframes drift` 60-90s 循环）+ 细噪点纹理（SVG feTurbulence data-URI @ 2.5% 透明度）。
- 页面滚动时背景不动（fixed），面板滚动——保证「同一屏内不同面板背后的内容不同」，材质差异可见。
