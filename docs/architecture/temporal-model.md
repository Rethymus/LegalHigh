# 时间模型（版本注册表与时间效力）

**实现**：`server/data/law_versions/*.json`（43 份；fail-closed 校验 `app/law_versions.py`：恰好一个 current、current 版本与语料元数据逐一一致——注册表不得比语料更先进）。多版本时间线 12 部（刑法四版本+12 修正案、民诉法六版本、未保法五版本等）；历史版本全文独立采集、只登记不进现行检索语料。

## 生效日期口径（快照自证纪律）

- 附则自载施行日为准（R65 scl 先例）；修正类新法取修正决定施行日（R136 著作权/专利先例：附则原版日跨数十年沿用、对现行版误导）——两说并存时在 pending_note 存档。
- 未施行新法 status 如实标注（商标法 2026「已公布（2027-01-01 施行）」）。

## 引用不变量

每条引用恒带 law_status/effective_date/source_url/label 四要素（完整率 1.0 评测钉住）——用户可自行核对时间效力。

## AS_OF_DATE 时间效力层（R144 检测/标记/告知 + R169 历史对照命中面）

**实现**：`app/temporal.py` + qa/search 接线 + `tests/test_temporal.py`（12 项钉住）：
- **检测**：明确年份（1949–当前+1，as_of 取年末保守边界）与指代词（当年/那时候/旧法…，只检测不解析）；
- **标记**：`in_force_at_as_of`（以语料 effective_date 比较；True 仅表示现行文本适用起点早于 as_of，其间修正差异由告知显式声明）；非时间上下文的响应形态保持不变（契约稳定）；
- **告知**：temporal 块（notice+limitation）声明「现行版本≠时点适用文本、系统不断言当时合法性」，指向版本时间线与官方原文。

**as_of 命中面（R169，known-gaps #1 收口）**：`app/version_fulltext.py::historical_for_card`——as_of 命中时为答案卡/检索命中附加 `historical_version`（适用版本判定=施行日与公布日均 ≤ as_of 中公布日最新者：附则跨修正延续口径下，公布日是区分「已通过未施行」的关键——刑法 2020 修正 as_of=2020-05 必须落 1997-revision）；对照文本按「同条号」给出，移位风险随行显式标注（版本间条号可能移位，仅供对照不自动断言适用）；适用版本即现行/无注册表/全文未采集时不出字段（契约稳定，增强 fail-open 不炸主链）。钉住：`tests/test_as_of_history.py`（7 项）。

**剩余白区**：跨版本条号重编号映射（重编号条文的精确历史定位）与历史文本的独立检索索引（现状=现行检索命中+同条号对照）。
