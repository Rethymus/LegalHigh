# 时间模型（版本注册表与时间效力）

**实现**：`server/data/law_versions/*.json`（43 份；fail-closed 校验 `app/law_versions.py`：恰好一个 current、current 版本与语料元数据逐一一致——注册表不得比语料更先进）。多版本时间线 12 部（刑法四版本+12 修正案、民诉法六版本、未保法五版本等）；历史版本全文独立采集、只登记不进现行检索语料。

## 生效日期口径（快照自证纪律）

- 附则自载施行日为准（R65 scl 先例）；修正类新法取修正决定施行日（R136 著作权/专利先例：附则原版日跨数十年沿用、对现行版误导）——两说并存时在 pending_note 存档。
- 未施行新法 status 如实标注（商标法 2026「已公布（2027-01-01 施行）」）。

## 引用不变量

每条引用恒带 law_status/effective_date/source_url/label 四要素（完整率 1.0 评测钉住）——用户可自行核对时间效力。
