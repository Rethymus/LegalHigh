# LegalHigh v1.1.0-rc.1

这是源码与静态站点预发布。This is a source and static-site prerelease.

- 14 部、2,380 条受控法条，新增四部全国人大官方快照；14 controlled instruments / 2,380 provisions.
- 六步事实梳理、受众选择、真实数据与本机草稿流程；fact preparation, audience views and local document workflows.
- 具名专业解读与原文关联，证据覆盖明确不等于正确率；named professional commentary with traceable sources, no invented accuracy percentage.
- AI 逐分句证据检查与结果承诺拦截；per-clause lexical evidence checks, not semantic correctness guarantees.
- 产品内部设计规范页已移除；internal design galleries removed.

## Downloads / 下载

- `LegalHigh-v1.1.0-rc.1-source.zip`: versioned source; follow README.zh-CN.md / README.en.md to run locally.
- `LegalHigh-v1.1.0-rc.1-pages.zip`: static site built for `/LegalHigh/`; no backend or online AI.
- `SHA256SUMS.txt`: checksums for both archives; checksums establish file integrity, not code signing.
- No desktop installers: cross-platform signed installation and upgrade verification are incomplete. 本次不提供未经完整验收的桌面安装包。

## Verification / 验证

Recorded local checks: 182 backend tests, build/lint, 5 discipline gates, 32 contrast combinations, 48 browser routes and a focused professional-commentary page check. These do not measure legal accuracy. Cloud verification links are available in the repository Actions tab.

## Upgrade / 升级

Back up SQLite and stop the old service first; reinstall locked dependencies and restart. Legacy verified/issued drafts migrate to reviewed/finalized as local user progress. Roll back with the pre-upgrade database backup. v1.0.0 installers lack subsequent fixes.

LegalHigh is a legal-literacy and evidence-navigation prototype. It does not verify lawyer credentials, issue legal documents or replace independent counsel. The corpus is incomplete. The repository has no open-source licence; publication does not grant a new licence.
