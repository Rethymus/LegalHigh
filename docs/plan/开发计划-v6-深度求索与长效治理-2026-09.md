## 二、外部调研（8 路，2026-09-14 核验）

| # | 源 | 关键发现 | 证据等级 |
|---|---|---|---|
| R1 | LegalBench-RAG 论文（arXiv:2408.10343，abs 页 2026-09-14 可达） | 法律 RAG 的**段落级精确检索**在通用管线上普遍很差（论文口径 precision/recall 常低于 50）——对比口径是「答案所在段落是否精确命中」，比本项目「条文级 hit@5」严格一档 | 【强】 |
| R2 | BGE-M3 模型页（huggingface.co/BAAI/bge-m3，2026-09-14） | MIT 许可；多语；单模型同时支持 dense/sparse/colbert 三检索模式；输入至 8192 token——中文法律文本嵌入候选。**但**：引入嵌入模型=引入非确定性组件（模型版本漂移），与「确定性可复现」harness 哲学冲突 | 【强】 |
| R3 | SQLite FTS5 文档（sqlite.org/fts5.html，2026-09-14） | FTS5 内置 **trigram tokenizer**（每三字符一 token），天然支持 CJK 子串匹配与 LIKE 加速——若语料规模增长（>2 万条）或需前缀/子串查询，是比自研 Python BM25 更可扩展的备选引擎 | 【强】 |
| R4 | PWA（MDN Progressive web apps，2026-09-14） | service worker + web manifest = 可安装、可离线、单代码库多平台——对「便民惠民」定位的弱网/内网/农村场景价值直接 | 【强】 |
| R5 | 《人工智能生成合成内容标识办法》（cac.gov.cn 官方发布页，2026-09-14） | 第 4 条：深度合成情形须加**显式标识**；第 5 条：文件元数据须加**隐式标识**（服务者名称/内容编号等）；第 14 条：**自 2025-09-01 施行**。本项目 AI 默认关闭且输出走人工审核双轨，暂不触发；但决策 12 分级开放任何一步扩张前，AI 草稿对外形态必须先落标识设计 | 【强】 |
| R6 | LawRefBook/Laws（GitHub API，2026-09-14） | 1.8k★，法律条文离线阅读器（SwiftUI/iOS）。生态位=阅读器，与本项目「引用工程+工作流」不同——无直接复用；但印证「权威法律文本的开源整理」需求真实存在 | 【中】 |
| R7 | llms.txt v2 规范（llmstxt.org，2026-09-14） | `/llms.txt`（站点根，markdown）向 LLM 提供站点内容索引，`/llms-full.txt` 提供全文——成本极低，让外部 AI 助手正确引用本项目口径（而不是幻觉出错误法条） | 【强】 |
| R8 | WCAG 2.2 新增标准（w3.org/WAI what's new in 2.2，2026-09-14） | AA 级新增=2.4.11 焦点不遮挡 / 2.5.7 拖拽 / 2.5.8 目标尺寸；本项目 2.4.11 与 2.5.8 已落地（qa_a11y 门）、2.5.7 全站无拖拽交互 N/A——**可访问性 2.2 实质完成**，剩余为 AAA（2.4.12/2.4.13）远期项 | 【强】 |

调研结论：**v6 的正确杠杆不在「更聪明的模型」，而在 ①离线可达（PWA）②评测口径升级（对齐 LegalBench-RAG 严格派生）③鸿沟子集量化 ④AI 时代的内容可被正确引用（llms.txt）⑤AI 扩张的合规预案（标识办法）。**

## 三、仓库内数据资产盘点：词法鸿沟实录

金标 168 组中 **11 组带词法鸿沟/改题实录**（6.5%），类型分布：

| 鸿沟类型 | 实例 | 数量 |
|---|---|---|
| 口语→法言（无条文词面） | 「别人打我我还手」vs「制止不法侵害」；「狗叫扰民」vs「饲养动物干扰正常生活」 | 5 |
| 同义数字写法 | 「两年」vs 条文「二年」 | 1 |
| 极短条文词面缺失 | 「仲裁要交钱吗」vs 第 53 条仅「不收费/经费/财政保障」 | 1 |
| 指代性表述 | 「错误拘留错误逮捕」vs「违反刑事诉讼法的规定…有取得赔偿的权利」 | 1 |
| 句式颠倒 | 「劳动既是权利也是义务」vs「有劳动的权利和义务」 | 1 |
| 委婉/黑话 | 「卖银行卡给跑分团伙」vs 帮信罪 | 1 |

全库 hit@5 95.83%（miss 4.2%）与 11 组鸿沟实录共同构成**语义检索再评估的数据资产**——v5 的触发条件「词法鸿沟数据积累」已实质成熟，缺的只是一个不换引擎也能量化的口径（S5-T2 鸿沟子集指标）。
