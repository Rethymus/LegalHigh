# ADR-0003：验证失败即关闭（fail-closed）

日期：2026-09-16（实践自第十七轮主体安全模型确立，本 ADR 形式化）

## 决策

一切验证不通过时拒绝而非降级继续：
- 敏感接口：无 LH_ADMIN_TOKEN 配置一律 503、缺令牌 401、错令牌 403；GateBody extra="forbid" 拒客户端自报 actor/role；
- AI 链路：无密钥 409；gate1 红线命中→文本扣留（output_withheld）；引用不一致→拒；
- 版本注册表：schema 问题 500、current 与语料不一致拒载；
- 检索：语料外问题低于拒答阈值→no_answer 显式拒绝（「本系统不会在无依据时生成内容」）；
- 法律正确地不回答 > 自信地胡说（FLERF 报告 §24）。

## 机械检查

边界探针 16 项（409/401/404/422 语义）；拒答正确率 1.0；注册表 6 测试。
