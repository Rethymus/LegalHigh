# ADR-0001：确定性 BM25 单引擎（不引入向量/词典检索）

日期：2026-09-16（决策2 于 2026-08-30 确立，本 ADR 补记并回应 FLERF 报告 §10 五路召回主张）

## 背景

FLERF 报告建议五路召回（Exact/BM25/Sparse/Dense/Graph）+RRF 融合。

## 决策

维持**服务端 BM25（bigram）单引擎**：Exact/Metadata（law_id 过滤+精确取条）与 Graph（同章/引用链接）作为既有形态并存；**不引入 Dense/Sparse/ColBERT**，除非 benchmark 证明值得成本。

## 理由

1. 报告自身 §11 论证 BM25 对法律精确标识符不可替代、§37 主张组件克制（「不是组件越多越前沿」）、§13 承认 ColBERT 全量索引成本会爆炸；
2. 实证数据：R83 THUOCL 词典 A/B 实验——词典增强使 hit@5 回退 -4.16%，bigram 天然交叉组合特征优于整词匹配；现行 248 组金标 hit@5 0.9556；
3. 确定性=可复现=审计友好：同查询同结果，是「引用不变量」与评测门的工程基础；
4. 原型期语料规模（43 部 5,573 条）远未到需要向量召回的规模阈值。

## 后果

- 语义鸿沟以**数据资产**形态管理：金标改题实录（40+ 条 layperson↔canonical 鸿沟）是未来语义检索再评估的基准集；
- 任何分词/检索变更必须先跑全量金标 A/B，回退超 1% 即撤销（硬规则⑲）。

## 复议条件

语料规模或鸿沟子集指标触发重新评估时，以 RAGChecker/STARD 式评测先行，凭数据开 ADR。
