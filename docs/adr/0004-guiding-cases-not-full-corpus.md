# ADR-0004：案例库只收官方指导性案例，不追求裁判文书全量

日期：2026-09-16（实践自 R78/R132 确立，本 ADR 形式化）

## 决策

案例库只收录可逐字核验的最高法**指导性案例**（官方发布页快照+逐字要点/结果+钉住测试）与少量域外经典判例（比较研究单列）。不引入公报案例（R132 评估：445 件以商事二审为主，与普法受众错配——不采纳理由已登记）；不宣称「收录中国全部案件」（部分裁判依法不公开）。

## 理由

1. 指导性案例是「应当参照」的高权威层（报告 §5），质量密度远高于普通裁判；
2. 全量文书与本项目「薄索引+按需」哲学冲突（报告 §5：人民法院案例库本身也不是全量库）；
3. 每件 100% 逐字钉住的质量纪律在批量数据上不可维持——宁缺毋滥是不编造红线的延伸。

## 复议条件

业主提供已核实的官方案例文本批量通道（或授权运营数据合作）时，按「官方源+快照+逐字校验+领域适配判断」同管线扩充。
