## 一、可直接复用的工具与数据

### 1.1 THUOCL（THU Open Chinese Lexicon）
- **GitHub**: thunlp/THUOCL | **⭐**: 1,129 | **License**: MIT ✅
- **内容**: 中文开放词库，含法律领域词表
- **复用方式**: 法律领域词表可增强 BM25 分词质量（jieba 替代方案的补充参考，决策 2 仍有效——仅展示层域词优先）与术语卡的术语发现
- **适配成本**: 低——仅取法律子词典，映射到本项目术语体系
- **AGENTS 已有引用**: 无

### 1.2 funNLP
- **GitHub**: fighting41love/funNLP | **⭐**: 83,101 | **License**: 未声明
- **内容**: 中英文 NLP 工具集，含法律词典、敏感词、实体抽取等
- **复用方式**: 法律词典子集可辅助术语卡增补与检索分词；但 license 缺失 → 仅作思路参考，不直接导入
- **适配成本**: N/A（仅参考）

### 1.3 cncases/cases
- **GitHub**: cncases/cases | **⭐**: 1,109 | **License**: MPL-2.0 ✅
- **内容**: 中国裁判文书网本地搜索——完整的裁判文书索引与检索系统
- **复用方式**: 参考其案例数据 schema（文书 ID/法院/案由/裁判日期/全文），为项目案例库扩充提供结构化模板
- **适配成本**: 中——需对照项目现有 cases.json schema 差异化

## 二、可参考的架构设计

### 2.1 CrimeKgAssitant（犯罪知识图谱助手）
- **GitHub**: liuhuanyong/CrimeKgAssitant | **⭐**: 1,585 | **License**: 未声明
- **内容**: 856 项罪名知识图谱 + 280 万罪名预测训练库 + 20 万法务问答对（13 类问题分类）
- **可参考**:
  - 罪名知识图谱 schema（罪名 → 构成要件 → 法条关联 → 刑罚幅度）→ 可映射到本项目「请求权要件检查」模块的知识表示
  - 13 类法律问题分类体系 → 可参考设计问答路由
- **不可直接用**: 280 万训练库涉及爬取裁判文书（红线 7）；KG 数据 license 未声明

### 2.2 law_ai（法律 RAG 助手）
- **GitHub**: billvsme/law_ai | **⭐**: 235 | **License**: 未声明
- **内容**: 200+ 法律手册 + 向量检索（Chroma）+ LLM + 网页搜索 → 问答 + 引用溯源
- **可参考**:
  - 多源检索架构（法条向量检索 + 网页搜索互补）→ 可参考设计未来的语义检索双通道
  - 引用溯源展示（回答附带法规条文与来源链接）→ 与本项目引用绑定 gate 理念一致
- **不可直接用**: 无 license；LLM 自由生成不可溯源（与本项目「确定性 BM25 + 不编造」哲学冲突）

### 2.3 contract-review（中文合同审查）
- **GitHub**: xiaodingfeng/contract-review | **⭐**: 149 | **License**: 未声明
- **内容**: 合同上传 + AI 预分析 + 审查点配置 + OnlyOffice 在线预览编辑 + 知识库
- **可参考**: 审查点配置化设计（用户可自定义审查规则）→ 可参考增强本项目的合同审查规则引擎
- **不可直接用**: UI 框架不同；AI 预分析依赖 LLM

### 2.4 legal-kb-builder（法律知识库构建）
- **GitHub**: Youchu-lawhub/legal-kb-builder | **⭐**: 6 | **License**: NOASSERTION
- **内容**: 从 PDF/DOCX/图片到可对外服务的业务咨询智能体——文档解析 → 知识提取 → 向量入库 → RAG 服务
- **可参考**: 多格式文档解析链（PDF → 结构化法条）→ 可参考增强 build_corpus 的输入源（当前仅 HTML/JSON 快照）
- ** Topics**: chinese-law, document-parsing, legal-ai, legal-tech, llm, mcp, rag, retrieval

### 2.5 Event-Extraction（法律事件抽取）
- **GitHub**: zhang17173/Event-Extraction | **⭐**: 610 | **License**: 未声明
- **内容**: 基于法律裁判文书的事件抽取——分词、词性标注、命名实体识别、事件要素抽取、判决结果预测
- **可参考**: 法律文本 NLP 管道设计 → 可参考增强案例摘要的结构化处理
- **不可直接用**: 训练数据涉及裁判文书（红线 7 相关）

## 三、可参考的评测基准

### 3.1 JEC-QA（司法考试问答数据集）
- **GitHub**: thunlp/jec-qa | **⭐**: 63
- **内容**: 中国司法考试问答数据集——法律知识问答的多选题与多参考答案题
- **复用方式**: 可作为法律问答系统的补充评测基准（现有金标 168 组测检索，JEC-QA 测理解）

### 3.2 CAIL2018（中国法研杯）
- **GitHub**: china-ai-law-challenge/CAIL2018 | **⭐**: 89
- **内容**: 罪名预测、法条预测、刑期预测三任务的中文法律 NLP 挑战赛数据集
- **复用方式**: 罪名预测/法条预测子任务可辅助验证检索质量（与金标 hit@5 互补）
