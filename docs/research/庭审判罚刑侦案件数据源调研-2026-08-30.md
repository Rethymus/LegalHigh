# 庭审 · 判罚 · 刑侦 · 案件数据源深度调研（2026-08-30）

> 目的：为 LegalHigh 补全国内外庭审、判罚、刑侦、案件数据建立**有据可依、合法合规**的获取策略。
> 方法：逐数据源核实官方性 / 许可 / 接入方式 / 规模，多个独立来源互相印证；每条结论附来源 URL。
> 纪律：本文档所有事实均有链接可溯；无法核实的推断明确标注。与《法律知识库项目深度调研报告》§5（P0–P3 路线）互为印证与细化。

---

## 一、中国司法公开数据：现状与政策边界（互证：最高法官方 + 人民日报/财新）

### 1.1 裁判文书网（wenshu.court.gov.cn）——「求全」轨，公开量收缩
- **事实**：每年上网文书从 2020 年 1920 万件、2021 年 1490 万件降至 2022 年 1040 万件（最高法相关部门负责人答记者问，https://ipc.court.gov.cn/zh-cn/news/view-2693.html）；人民日报《中国裁判文书网十年不易》（2024-01-30）证实 2021 年起逐年下降，原因是隐私/商业秘密与安全风险的严格筛查（http://paper.people.com.cn）。
- **推论（有据）**：批量抓取路径已不可行也不合规——数量收缩 + 反爬限制 + 文书含个人信息。**本项目策略：不爬取**。裁判文书以「授权合作 / 官方开放数据集」为唯一接入路径（见 §二 CAIL）。

### 1.2 人民法院案例库（rmfyalk.court.gov.cn）——「求精」轨，向社会开放
- **事实**：2024-02-27 正式上线并向社会开放，入库案例 3711 件（刑事 1453 / 民事 1643，https://www.court.gov.cn/zixun/xiangqing/426222.html）；至 2025-07-15 达 5040 件（刑事 1912 / 民事 2159），覆盖常见罪名与多发案由；配套《人民法院案例库建设运行工作规程》，入库案例供法官办案参考。与裁判文书网「互为补充」。
- **策略**：**P1 级优先接入**。向社会开放但需注册账号，无公开批量 API → 走「注册账号 + 人工/半自动按篇录入 + 官方文本核对」，每件入库案例天然经过最高法审核，与本项目「可溯源 + 官方性」纪律完全相容。前端案例来源层级已预留「参考案例」位。

### 1.3 庭审公开网（tingshen.court.gov.cn）——庭审直播/庭审实录
- **事实**：全国 31 省市+新疆兵团所有法院接入；一项实证研究统计民事案件直播约 1566 万余场（学术统计口径）。
- **策略**：P2。庭审录像的公开粒度与检索 API 有限；先以「庭审程序科普 + 直播链接引用」形态服务普法（链接到官方平台，不自存录像），文本化庭审实录待官方开放接口。

### 1.4 两高官方发布渠道（正式文本，零门槛合法获取）
- **最高法**：指导性案例（最高法公报 gongbao.court.gov.cn / 官网典型案例栏目 https://www.court.gov.cn/zixun/gengduo/104_3.html）。
- **最高检**：指导性案例与典型案例通过官网「网上发布厅」发布正式文本（spp.gov.cn / 12309 网上发布厅），批次持续更新（如 2026 年知识产权保护、个人信息保护公益诉讼等批次）；「检察案例库」2022 年上线但面向检察人员内部检索（中国日报 https://cn.chinadaily.com.cn/a/202202/25/WS6218b84fa3107be497a07d50.html）。
- **策略**：**P0 立即可做**（已在做：指导案例 24/23 号）。扩录路径 = 官网正式文本 → 人工结构化 → 来源标注「官方发布文本」。每批 6–10 件、由官方审定，质量与合规性最高。

## 二、国内开源学术数据集（CAIL 系列）——「判罚/刑侦」数据的合规批量来源

- **事实（互证：GitHub 官方仓库 + 学会官网 + 镜像平台）**：
  - **thunlp/CAIL**（https://github.com/thunlp/CAIL）：中国法研杯官方仓库，数据集来自**中国裁判文书网的刑事法律文书**，CAIL2018 规模 **268 万份**，覆盖 202 个罪名、183 条法条，刑期 0–25 年（含无期/死刑），三大任务=罪名预测 / 法条推荐 / **刑期预测（判罚）**；官方提供评分程序。
  - CAIL2019（https://github.com/thunlp/CAIL2019）：阅读理解、要素识别、相似案例匹配；CAIL2022 等历年延续。
  - 镜像：飞桨 AI Studio（aistudio.baidu.com/datasetdetail/103667）、Heywhale；汇总整理见 CSDN LegalAI 数据集综述（blog.csdn.net/polarisrisingwar/article/details/126058246）。
  - 另：国家基础学科公共科学数据中心提供裁判文书刑/民文本数据集约 27 万篇。
- **可行性互证**：数据出自裁判文书网公开文书（当时合法公开），由清华大学/中国中文信息学会组织发布，学界广泛使用（北京大学学报量刑预测论文即基于此类数据）——来源合法性与学术可用性双确认。
- **合规红线（本项目附加）**：文书含当事人个人信息。**入库前必须二次脱敏审查**（姓名→匿名代称、证件号/住址删除），并在前端标注「来自公开学术数据集 · 已脱敏处理 · 仅供研究参考，不构成裁判依据」。PIPL 拒绝/删除通道对这类数据同样适用（当事人可请求移除）。
- **策略**：**P1**。按「罪名×法条×刑期」选代表性子集（如盗窃/危险驾驶/民间借贷纠纷各数百篇）入案例库「研究样本」区，用于判罚参考与类案统计——**展示统计与研究性结论，绝不展示为个案裁判依据**。

## 三、国外开放判例与法庭数据（全部有官方 API / 开放许可）

### 3.1 CourtListener / Free Law Project（美国，非营利 501(c)(3)）
- **事实**：免费法律检索引擎，收录**数百万**联邦与州法院 opinions、RECAP Archive（免费 PACER 文书与 docket）、法官档案、庭审录音；REST API + 批量数据（bulk），覆盖 3,359 个辖区（https://www.courtlistener.com/ 、https://free.law/projects/courtlistener/ 、辖区列表 https://www.courtlistener.com/help/api/jurisdictions/ 、批量数据 wiki https://wiki.free.law/c/courtlistener/help/api/bulk-data/bulk-legal-data 、官方 Python 客户端 https://github.com/freelawproject/courtlistener-api-client）。
- **策略**：**P1**。API 只读接入，先接 opinions 检索（美国判例详情页引用），对齐已有 Brown/Miranda 样例的呈现模式（域外资料·比较研究）。

### 3.2 Harvard Caselaw Access Project（CAP，case.law）
- **事实**：哈佛法学院图书馆扫描的 **670 万+ 件美国判例**（360 余年、约 4000 万页）数字库；**检索与 API 已迁移至 Free Law Project**，全量数据继续在 case.law 提供浏览与 **bulk 下载**（https://case.law/ ；HuggingFace 镜像 https://huggingface.co/datasets/free-law/Caselaw_Access_Project ；国会图书馆对比指南 https://guides.loc.gov/free-case-law/caselaw-access-project）。
- **策略**：**P2**。历史判例 bulk 语料用于「法律制度演进/比较研究」专题；美国判例多为公有领域（政府作品）+ CAP 明确开放——版权风险低，仍标注来源与「比较研究」定位。

### 3.3 立法开放数据（已在路线，补充许可细节）
- **legislation.gov.uk**：官方 API（https://www.legislation.gov.uk/developer 、OpenAPI 规范 https://www.legislation.gov.uk/openapi 、数据模型文档 https://github.com/legislation/data-documentation），**Open Government Licence v3.0**（data.gov.uk 数据集页明确标注；个别源自 EUR-Lex 内容有例外声明）。
- **EUR-Lex / CELLAR**：RESTful API + SPARQL endpoint + 批量下载（https://eur-lex.europa.eu/content/help/data-reuse/reuse-contents-eurlex-details.html 、CELLAR https://op.europa.eu/en/web/cellar），免费再利用、受版权条件约束，法律依据 (EU) 2019/1024 开放数据指令。
- **策略**：**P2**。接入后支撑「跨法域对比」页的逐字原文（当前为人工录入要旨）。

## 四、刑侦与犯罪统计（背景资料层，非个案）

- **FBI Crime Data Explorer**（https://cde.ucr.cjis.gov/）：UCR 统一犯罪报告官方平台；**FBI Crime Data API 只读服务，返回 JSON/CSV**（美国司法部开发者页 https://www.justice.gov/developer ；官方 GitHub https://github.com/fbi-cde/crime-data-api 、18f/crime-data-explorer）。
- **data.police.uk**：英格兰/威尔士/北爱尔兰犯罪与警务开放数据，**街面级犯罪、结案、截查数据 CSV + REST API，OGL 许可**（https://data.police.uk/ ）。
- **中国侧**：国家统计局（data.stats.gov.cn）与地方公共数据开放平台（上海 data.sh.gov.cn / 浙江 data.zjzwfw.gov.cn）含司法行政类统计；无个案级开放。
- **策略**：**P2–P3**。以「犯罪与司法统计」专题卡形式呈现（如「美国 FBI 犯罪统计（官方 API）」「英国街面犯罪数据（OGL）」），服务研究与普法场景；明确标注统计口径差异，不与中国数据直接对比下结论。

## 五、总体接入策略（P0→P3 优先级）与合规红线映射

| 优先级 | 数据源 | 方式 | 合规锚点 |
|---|---|---|---|
| **P0（进行中）** | 两高指导性案例/典型案例官方文本 | 官网正式文本 → 人工结构化 → 来源标注 | 官方发布文本，零授权风险；引用不变量 |
| **P1** | 人民法院案例库（参考案例） | 注册账号 + 按篇录入 + 官方文本核对 | 向社会开放；遵守账号条款；不批量抓取 |
| **P1** | CAIL 开源数据集 | 官方 GitHub/镜像下载 → **二次脱敏** → 研究样本区 | 数据源自公开文书、学术发布；PIPL 脱敏+拒绝/删除通道 |
| **P1** | CourtListener API（美国判例） | 只读 REST API | 非营利开放数据；域外资料免责定位 |
| **P2** | CAP bulk / EUR-Lex CELLAR / legislation.gov.uk API | bulk 下载 / REST（OGL/版权条件） | 开放许可；逐源标注许可类型 |
| **P2** | FBI CDE / data.police.uk 统计 | API 接入，统计专题卡 | 官方统计开放数据 |
| **P2** | 庭审公开网 | 链接引用 + 庭审程序科普 | 不自存录像；官方平台为准 |
| **不做** | 裁判文书网批量抓取 / 检察案例库（内部系统） | — | 反爬与授权边界；PIPL 风险 |

**防幻觉机制**（与目标直接对应）：
1. 每条新数据入库前过「来源三问」：官方性（谁发布）？许可（能否用）？核验（文本与哪份官方原件对照）？
2. 案例记录强制字段 `source_note` + `verified`（前端未核实即灰态禁止引用）——现有 cases.json 纪律已实现；
3. 数据源页只展示「已接入/规划接入/未接入」真实状态，不虚构任何接入（已实现，本轮细化）；
4. 所有统计性表述使用「公开数据/研究中观察到……」句式（Legal Safety §45），不输出确定性结论。
