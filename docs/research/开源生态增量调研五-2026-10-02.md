## 二、harveyai/harvey-labs（1401★，MIT）——Harvey 法律 Agent 基准（LAB）【强·README+docs】

开源法律 Agent 基准：2010 任务、24+ 执业领域、rubric 判分 + 执行 harness。**MIT 许可——
方法论可自由吸收**。

### 评测方法论对照（docs/eval-strategies.md）

| LAB 口径 | 本项目现态 | 判定 |
|---|---|---|
| rubric 内联于 task.json，等权二元判据 | 四问判分=等权二元（逐问 pass/fail） | 已对齐 |
| 每判据显式 `match_criteria`（「PASS if… FAIL if…」） | 四问判据在 judge 内部逻辑，未显式外化 | **本轮实施** |
| all-pass 计分（全过=1.0 否则 0.0） | 四问门=全部 pass 才交付 | 已对齐 |
| 双独立 LLM judge（语义判分） | 确定性结构判分（零模型零配额） | 哲学差异如实登记：LAB 需配额，本项目确定性门可离线跑——离线可复现性是本项目评测的硬约束，双 judge 待 10-03 窗口后作为可选增强评估 |
| 无关键词/正则匹配，全语义比较 | 结构判分（章节/引用存在性）+ 编造条号确定性检出 | 互证：结构面确定性更可靠，语义面待配额 |

**实施（本轮）**：FOUR_QUESTIONS 常量加显式 `criteria`（「PASS：… FAIL：…」逐问判据，
LAB match_criteria 形态），judge 逐问输出携带 criteria——在线评测读数从「失败+违规列表」
升级为「失败+违规+该问的显式判据」（读数自文档化，最小修复单元定位更直接）。
