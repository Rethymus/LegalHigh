## 一、zeweihan/aiworkdeck（148★，AGPL-3.0）——专业文档 AI 工作区【中·README】

「从素材到可审阅交付件——从法律工作开始」：代理（agent）与文档编辑器/项目文件/来源
引用/版本历史**同屏协作**，律师在文档中检查 AI 修改并逐条接受/拒绝。

| 功能 | AI WorkDeck | 本项目 | 判定 |
|---|---|---|---|
| 可审阅代理修改（redline） | 编辑器内 tracked changes + 逐条 accept/reject | ✅ DOCX w:ins/w:del + 回传三态解析 | **已对齐**（交付形态不同：IDE vs 离线 Word） |
| 来源链接（source-linked） | every finding needs a source | ✅ 引用绑定（citation_of 校验） | **已对齐** |
| 三方 diff（original/AI/final） | three-way diff | ✅ compare.py 两方 + 回传状态机 | 部分对齐（三方是 UX 层不是能力缺失） |
| 文档结构保留 | 保留段落/编号/样式 | ✅ docxgen 按规范排版 | **已对齐** |
| 版本历史 | 项目级版本历史 | ✅ 版本注册表+审计日志 | **已对齐** |
| 插件运行时 | plugin runtime | ✅ AI 模型插件层（8 提供方） | **已对齐** |

**判定**：AGPL-3.0 零代码引入（与 mike 同判定）。核心能力面**已全部对齐**——本项目以
「离线 Word + 确定性引擎」实现同等功能面，AI WorkDeck 以「IDE + LLM 编排」实现，
是两种交付形态对同一功能面的平行实现。登记为**架构互证（第七个同构项目）**。
