# 开源生态增量调研（2026-09-24）

## 调研范围

在既有六轮调研（R79/R90/R106/R114/R117/R122，覆盖矩阵见 docs/research/开源生态覆盖审计-2026-09-16.md）基础上，本轮定向检索最新更新的法律 NLP / 检索 / MCP 生态。

## 新发现

### 1. matematicsolutions ELI MCP 连接器家族（多国立法 MCP）
- 14+ 个国家/地区的立法 MCP 服务器（荷兰/日本/澳大利亚/土耳其/匈牙利/以色列/马耳他/法国/卢森堡/芬兰/意大利等），全部基于各国官方 ELI（European Legislation Identifier）开放 API
- **可参考点**：验证了 LegalHigh MCP 六工具的设计模式与国际趋势一致；ELI 标准化标识符（类似本项目 flk bbbs）是跨国法律数据互操作的关键
- **判定**：架构参考已充分（本项目 MCP 已落地），不引入代码

### 2. eyecite-ts（TypeScript 法律引用提取，MIT，7KB 零依赖）
- 美国法 Bluebook 体系引用解析：案例引用/法规引用/期刊引用/短形式解析/平行链接
- 模式驱动架构（patterns/ 目录分类型组织）
- **可参考点**：模式驱动的引用提取架构——本项目 xrefs 提取已用类似正则模式，结构可对比
- **判定**：不含中国法模式（美国法专用），不引入；架构模式已对齐

### 3. SG-LegalCite（新加坡法律引用检索 benchmark，AACL-IJCNLP 2026）
- 原则增强的法律引用检索评测基准（MIT），昨日更新
- **可参考点**：评测基准设计——本项目金标 541 组同属引用检索评测，方法论已对齐
- **判定**：数据为新加坡法（不可直接复用）；评测方法论已在项目内实践

### 4. coreline-ai/graphify-legal-wiki（韩国法律知识图谱，MIT）
- 韩国法令判例知识图谱 + FastAPI/React 图谱聊天
- 与本项目同技术栈（FastAPI + React）
- **可参考点**：知识图谱与聊天的整合方式
- **判定**：韩国法数据不可复用；本项目 citator + 引用网络已覆盖同等功能

### 5. TBI-AI-Incubator/codify（法律书→Akoma Ntoso，5★）
- 将法规书转为 Akoma Ntoso XML 格式（OASIS 标准）
- **可参考点**：已在 R117 调研中登记（立法文档标准调研），维持「gated on 下游需求」判定

## 结论

本轮调研确认：**开源法律科技生态的最新发展（MCP 标准化/引用提取/评测基准）与本项目已有实现方向高度一致**，无新增可直接引入的代码依赖。增量边际收益持续趋零（与 R123 覆盖审计结论一致）。

**唯一可执行的改进**：SG-LegalCite 的评测维度（principle-augmented）启发了一个新评测口径——本项目可增加「引用精度」指标（金标命中引用的法律准确率 vs 法条准确率的分离度量），但这需要修改金标标注维度，属于金标扩容制度（决策 13）范畴，不在本轮实施。
