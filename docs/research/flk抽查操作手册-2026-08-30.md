# flk 人工抽查操作手册（决策项6·比对口径落地用）

> 目标口径（登记册 C4/决策项6）：**人工抽查 ≥10%（分层抽样）+ 字段级全量对照**，页面如实标注抽查口径与日期。禁止批量抓取（红线 7）。

## 一、机器侧（已完成，可重复执行）

```bash
cd server
.venv/Scripts/python.exe scripts/corpus_selfcheck.py
```

自检内容：条数 vs manifest、条号顺序连续性（独立重验切条）、文本非空、条号唯一、全量 citation_of 可解析、施行日期缺登。产物：`docs/qa-evidence/corpus_selfcheck_<date>.json`。

## 二、人工抽查（≥10%，预计 2–3 小时/千条）

### 抽样规则（分层，保证每部法律都被覆盖）
- 每部法律：首条 + 末条（必查，覆盖 pcl-2023 末条「试行废止」疑点）
- 每部法律：从高频引用条文（审查点 L1–L6/F1–F4/A1–A2 引用集 + 金标 expect 集）中各取 5 条
- 剩余额度按各部法律条数占比随机抽取（随机种子 20260830，可复现）
- 合计 ≥195 条（1,953 × 10%）

### 单条比对步骤（每条约 40 秒）
1. 打开 flk.npc.gov.cn → 检索法律名称 → 进入现行有效版本
2. 定位到条号，逐句对照 `server/data/laws/<law_id>.json` 的该条 `text`
3. 记录三类差异：**文本差异**（一字之差也要记）/ **效力字段差异**（施行日期、状态）/ **条号错位**
4. 在 `docs/research/evidence/flk_check_<date>.md` 表格登记：`law_id#no | flk 表述 | 本库表述 | 差异类型 | 处理`

### 通过标准（写入 M6-T1 验收）
- 抽查样本：文本差异 0 处、效力字段差异 0 处 → 登记该批次为「flk 抽查通过（N 条，<日期>）」
- 发现差异：逐条修订 `server/data/laws/`（走 build_corpus 证据流程，禁止手改 JSON）→ 重跑自检 + 全量金标

### 字段级全量对照（机器辅助 + 人工确认）
- 条数、公布机关、公布日期、施行日期：与 flk 法律详情页头部字段逐一对照（8 部法律 × 4 字段 = 32 项，约 20 分钟）
- 差异处理同上

## 三、状态标记
比对完成后：`server/data/laws/manifest.json` 增补 `flk_verified: {"scope": "抽查≥10%+字段全量", "date": "...", "sample": N, "diff": 0}`，前端法条详情「证据快照语料·建议以 flk 复核」改为「flk 抽查比对通过（N 条，<日期>）」。
