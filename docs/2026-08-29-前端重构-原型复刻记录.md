# 2026-08-29 前端重构：按原型图一比一复刻（v5 LawEdge AI 工作台）

## 任务与结论

创始人下达指令：**「通过视觉能力结合所给的原型设计图，一比一精准复刻从而实现彻底重构前端框架」**，并附产品思考（权威法源分层、证据链/零幻觉工作流、合同审查与文书起草实务化、中外对照合法边界、Apple HIG 语义材质 Token）。

已完成：新前端外壳按原型图 1:1 复刻并通过双视口截图比对（`docs/design/preview-1560.png`、`preview-1280.png`）；v4 全功能前端整体归档，后端与测试零影响。

## 新外壳（web/src）

- 版式：1548px 设计幅面海报式组合——上排主控台（932px：玻璃侧栏 192px + Hero 240px + 四功能卡 + 今日案例/法律快讯/跨法域对比）+ 目标用户画像（272px）+ 研究面板（高价值发展方向 / MVP 路线图 / 数据来源与合规保障）；下排文书工具（合同起草：格式库/编辑器/智能建议/状态栏）+ 案例详情（Brown v. Board，六标签页 + 中外对比卡）+ 设计系统规范（深色四宫格）；下排三窗口按原型错落（top-offset 26/0/56px）。
- 小视口 fit-scale：`App.tsx` 以 `min(1, vw/1548)` 等比缩放整幅，1280 视口完整呈现（与原型整框构图一致）。
- 技术：React 19 + TS + Vite 8（沿用 v4 依赖），**无组件库**——9 个手写组件 + `data/content.ts` 集中文案 + `styles/global.css` 单一样式表（Token 依据 Apple HIG：#F5F5F7/#1D1D1F/#0A84FF、深色 base/elevated、3px 焦点环、玻璃仅用于导航层）。
- 交互：侧栏激活态、模板选择、智能建议三标签、案例详情六标签（仅「判决结果」有原型内容，其余显示诚实空态）、收藏切换、轮播点、设计系统开关与 Aa 高对比切换、全站 hover/focus-visible。

## 取代与存档关系（重要）

- `web/src`（v5 外壳，静态复刻）**取代** v4 版式作为默认前端；`npm run build` 产物即新外壳。
- v4 全功能前端（TDesign + 8 页路由 + `lib/api.ts` 对接 server）整体移入 `web/src-legacy-v1/`，**未被删除**；AGENTS.md 中 v4 控件硬规则在功能回接时继续有效。
- `server/`（FastAPI、1,647 条语料、39/39 测试）不受影响；但 v4 前端与 server 的 API 接线随存档暂离——新外壳目前为静态复刻。

## 功能回接映射（M5 前置任务）

| 新外壳位置 | 对接 server API（v4 页面） | 说明 |
|---|---|---|
| 主控台·法条检索/法规条文 | `/api/qa`、corpus 检索（v4 `/qa`、`/research`） | 命中条文卡片=引用不变量 |
| 主控台·案例检索/今日案例 | 判例库（待授权数据，M5+） | 原型示例内容，接真数据时替换 |
| 文书工具·智能建议 | `/api/review`（14 审查点 + 采纳/驳回留痕） | 高/中风险卡=风险等级\|依据\|建议 |
| 文书工具·生成 | `/api/drafting`（DOCX 实务排版） | 律师函保持核验签发双轨 |
| 案例详情窗口 | `/api/case*`（案件分析三视角） | 中外对比卡遵守报告 §6 边界 |

回接时恢复方式：`web/src-legacy-v1` 中的 `lib/api.ts`、pages 逻辑可整体搬运，v4 页面路由改为新外壳的窗口内视图。
