# 生成式 AI 服务备案材料清单（M8-T1·决策 5 触发条件之一）

> 依据纪律：本清单逐条溯源到语料内《生成式人工智能服务管理暂行办法》（`server/data/laws/genai-2023.json`，证据快照）原文条文，标注「办法 §N」。凡语料未覆盖的程序性细节（材料表格样式、受理部门窗口），以国家网信办「互联网信息服务算法备案系统」及属地网信部门当期公布为准——**不虚构**，标注「以官方当期公布为准」。
> 适用判断（办法 §17 原文）：「提供具有**舆论属性或者社会动员能力**的生成式人工智能服务的」→ 安全评估 + 算法备案。LegalHigh 当前定位为法律信息检索与文书辅助工具原型，是否构成舆论属性/社会动员能力，**须由法务按《具有舆论属性或社会动员能力的互联网信息服务安全评估规定》认定**——本清单按「构成」的从严口径编制。

## C. 项目侧已完成、可直接作为申报附件的工程事实

1. **引用不变量**：每条输出绑定语料条文（`citation_of` 启动期硬校验），语料 8 部 1,953 条 0 自检问题（`corpus_selfcheck` 2026-08-30）。
2. **人工核验 gate**：律师函 draft→verified→issued 状态机（`role=执业律师` 强制）。
3. **AI 三道 gate**：红线词/引用绑定/审计留痕（`ai_governor.py`，默认关闭）+ 抽样评测 harness（`scripts/llm_eval.py`）。
4. **append-only 审计**：批注/签发/投诉/删除/审核全量留痕（`audit_log`，`/api/audit` 公示）。
5. **PIPL 通道**：删除（reviews/drafts/complaints 级联+审计）与导出（`/api/privacy/export`）。
6. **数据来源公示**：数据源页 17 源如实标注接入状态；flk 比对口径「人工抽查≥10%+字段全量」（`flk抽查操作手册`）。

## D. 流程（按办法 §17 语料原文 + 官方当期公布为准）

1. 法务认定舆论属性/社会动员能力（从严口径下按「是」准备）。
2. 完成 A1（选定已备案模型提供方并取得备案使用证明）。
3. 提交安全评估 → 算法备案（互联网信息服务算法备案系统）。
4. 备案通过 → 合规中心公示 B1–B6 → 触发决策 5「内网部署准备」（`docs/plan/决策清单-2026-08-30.md` 决策 5）。
5. 公网开放前：M8 验收 gate ③ checklist 逐项签核。
